# HomeOps Style Guide

This document outlines the comprehensive branding guidelines for HomeOps — brand voice, visual elements, and UI/UX patterns — to ensure consistency and reinforce our core message of **precision, control, and reliability**.

## 1. Brand Voice (Agentive Voice)

The HomeOps brand voice communicates capability, guidance, and reassurance. It embodies a trusted, efficient, and precise assistant.

- **Tone:** Clear, commanding, reassuring, action-oriented, respectful, precise, efficient, calm.
- **Purpose:** Communicate as a capable guide, focusing on the next best action for users, empowering them with control.
- **Copy Transformation Principle:** Always emphasize empowerment and control for the user.
  - *Before:* "Your refrigerator might need service."
  - *After:* "Take Command: Schedule your refrigerator diagnostic check."
- **Do's:**
  - Lead with action verbs.
  - Keep messages calm, specific, and direct.
  - Use language that instills confidence and capability.
- **Don'ts:**
  - Use vague, passive, or intimidating language.
  - Employ jargon without clear explanation.

## 2. Colors

HomeOps uses a focused color palette to convey reliability, trust, and clarity.

| Token | HEX | Usage |
|---|---|---|
| **Deep Green** (Primary) | `#005B5D` | Dominant color for primary branding elements, headers, key actionable items, and backgrounds where reliability and trust need emphasis. Signifies stability and growth. |
| **White** (Accent/Text) | `#FFFFFF` | High-contrast text against Deep Green, clean backgrounds, essential UI elements requiring maximum legibility. |
| **Light Gray** (Secondary Accent) | `#F0F0F0` | Subtle backgrounds, borders, dividers, and secondary UI elements — visual separation without competing with the primary green. |

## 3. Typography

A modern sans-serif font ensures clarity, professionalism, and readability across all touchpoints.

- **Primary Font:** Inter (recommended)
- **Fallback:** sans-serif
- **Usage:** All headings, body text, and UI labels. Inter is chosen for its legibility, modern aesthetic, and versatility across digital and print mediums.
- **Weights:** Maintain consistent use of weights (Regular, Medium, Bold) to establish hierarchy and emphasis.

## 4. Logo

The HomeOps logo is a core identifier, symbolizing control and precision within the home.

- **Design:** A distinctive house icon integrated with a circular design.
- **Symbolism:** The house represents "Home"; the circular design signifies "Ops" — operations, control, and precision.
- **Usage:** Must be used consistently without alteration of proportions, colors, or elements. Ensure adequate clear space around the logo.

## 5. Iconography

HomeOps iconography is simple, intuitive, and immediately recognizable.

- **Style:** Line-based or subtly filled, immediately intuitive. Avoid ornate or complex designs.
- **Key Icons:**
  - **Appliance Dashboard** — central management and overview
  - **Manual Access** — access to documentation / user manuals
  - **Repair Scheduler** — scheduling services
  - **Pro Chat** — direct communication with professionals
- **Usage:** Icons complement text labels or stand alone to convey function clearly. Maintain consistent sizing and spacing within UI elements.

## 6. UI/UX Patterns

UI/UX patterns reinforce precision, control, and user empowerment through consistent visual elements and interactive behaviors.

- **Consistency:** Maintain consistent use of defined colors, typography, and interactive element styles across all platforms and screens.
- **Call-to-Action (CTA):** Use clear, prominent CTA buttons — easily identifiable, purpose immediately understandable. Primary CTAs use Deep Green.
- **Navigation:** Intuitive structures that prioritize user-friendly access to core functionality.
- **Icon Usage:** Employ iconography judiciously to enhance understanding and reduce cognitive load. Icons should be easily decipherable and universally recognized in context.

### Specific Patterns

**Corner Brackets**
- **Purpose:** Visually frame important content, data fields, or interactive areas — subtly suggesting boundaries, focus, and precision. A non-intrusive way to highlight critical information or action zones.
- **Usage:** Apply sparingly to draw attention to key interactive components, data visualizations, or input-required sections. Frame content without enclosing it entirely — typically at the four corners of a rectangular area. Color should be a subtle variant of Deep Green or neutral gray.

**Focus Rings**
- **Purpose:** Clearly indicate the active or selected interactive element for accessibility and feedback, particularly for keyboard navigation. Reinforces user control and precise interaction.
- **Usage:** A distinct yet refined ring (e.g., thin outline in Deep Green or a complementary accent) around any interactive element (buttons, input fields, links) on keyboard focus. Visible but not distracting; high contrast against the background.

**Grid Modules**
- **Purpose:** Establish a clear, organized, scalable layout structure that emphasizes order, efficiency, and system-level control. Ensures visual harmony and predictable content arrangement.
- **Usage:** All layouts adhere to an underlying grid system (e.g., 8-point or 4-point grid). Content blocks, components, and spacing align to grid modules. Applies to responsive design and consistent spacing.

**User Empowerment:** All designs and interactions prioritize user-friendly navigation and straightforward messaging, ensuring users feel capable and in command of their home operations.

## 7. Touchpoint Intent

Each user touchpoint is designed with a specific intent to build confidence and facilitate action.

- **Splash Screen:** Conveys immediate confidence and a sense of welcome.
- **Command Card:** Offers instant access to critical information or immediate actions.
- **Embroidered Polo Shirt:** Projects professional trust and reliability, aligning the human element with the brand's core values.
